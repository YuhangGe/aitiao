# 爱跳跳（aitiao）

> ℹ️ **大模型驱动的自动跳广告工具**

> ⚠️ **声明：本项目提供安卓无障碍能力搭配视觉大模型能力的示例代码，不提供 APK，仅供开发者学习源代码。任何个人或组织克隆代码并构建 APK 后不得在公开渠道分发，一切违反法律犯规的行为自行承担后果，与本仓库无关。**

> 📢 **本项目代码完全使用 DeepSeek 生成，App 图标使用豆包生成。**


## 为什么有这个项目？

想用安卓上自动跳广告的工具，但“无障碍”权限实在是太敏感了，不放心，就自己写一个放心的工具。

## 这个项目有什么特色？

检测顺序是：**负缓存 → 正缓存 → 文本先点（仅无缓存）→ AI 首点**。

1. **负缓存**：AI 确认过不是广告的页面，直接放弃，不再做文本点击。
2. **正缓存**：AI 确认过的广告页，直接点击缓存的跳过坐标。
3. **文本先点（仅无缓存）**：启动窗口内先找“跳过 / skip”节点，命中立即点击，不等 AI。
4. **AI 首点**：没有文本、没有缓存，或缓存点击失败时，截图给视觉大模型判断并点击。

文本点击不是“点完就完了”，而是“**先点、后确认**”：

- 点击前先截一张图，点击后把这张图加上红圈（标出刚刚点击的位置）发给 AI；
- AI 使用独立的确认提示词，判断“这是不是广告页”“红圈是不是跳过按钮”“真正的跳过按钮在哪”；
- AI 判定非广告 → 写负缓存；判定广告且找到了真正的跳过按钮 → 写正缓存（优先用 AI 坐标）；红圈不是跳过但找到了真正的跳过 → 用真实坐标修正缓存；红圈是跳过但模型没给坐标 → 用点击点写正缓存；判定是广告但没有任何可用跳过按钮 → 写负缓存，避免下次继续文本误点；确认请求失败 → 不写缓存；
- AI 确认在后台执行，不阻塞点击。代价是点击前多一次本地截图，第一次点击仍可能误点，AI 只负责修正后续缓存。

页面指纹包含屏幕尺寸、density、Activity 和节点特征，所以横屏/竖屏、折叠态/展开态会得到不同的 key，不会拿一个方向的坐标去点另一个方向。缓存再带应用版本、时间戳和是否 AI 确认：应用升级会自动失效；正缓存 30 天、负缓存 1 天，不需要再手动清缓存。

代码整体上仍然很小，只有一个网络出口，要审查有没有留后门或其它安全隐患也很容易。

Release 包仅不到 3M 大小。

## 怎么使用这个项目？

1. 阅读项目所有代码，或者使用各种 agent + llm 来审计下代码，确保没有任何安全隐患自己可以放心使用。
2. 安装并配置好 android studio 开发环境后，直接构建项目并打包出 apk，安装到自己的设备上。
3. 在配置页确认大模型参数。默认已经是 DeepSeek `deepseek-flash` + `https://api.deepseek.com`；也可以换成其它兼容 OpenAI 的视觉模型。
4. 整个过程如果遇到报签名文件找不到一类的问题，直接让 agent 帮解决就行。
